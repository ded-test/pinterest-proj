Описание компонентов

1. main.py
    Запускает приложение FastAPI и включает маршруты.

2. models/
    Содержит модели данных, определенные с помощью SQLAlchemy:
    user.py: Модель пользователя с полями, такими как id, username, email, password_hash.
    pin.py: Модель пина с полями, такими как id, title, image_url, user_id, board_id.
    board.py: Модель доски с полями, такими как id, name, user_id.

3. schemas/
    Содержит схемы Pydantic для валидации данных:
    user.py: Схема для регистрации и аутентификации пользователя.
    pin.py: Схема для создания и обновления пинов.
    board.py: Схема для создания и обновления досок.

4. routes/
    Определяет маршруты API для работы с ресурсами:
    user.py: Регистрация, вход, получение информации о пользователе.
    pin.py: CRUD операции для пинов.
    board.py: CRUD операции для досок.

5. services/
    Содержит бизнес-логику приложения:
    auth.py: Логика аутентификации, включая JWT.
    user_service.py: Логика работы с пользователями.
    pin_service.py: Логика работы с пинами.
    board_service.py: Логика работы с досками.

6. database.py
    Настройка подключения к базе данных PostgreSQL и создание таблиц.

7. config.py
    Конфигурация приложения, включая настройки базы данных и секретные ключи.

8. tests/
    Содержит тесты для проверки функциональности API.

9. requirements.txt
    Список зависимостей проекта, таких как FastAPI, SQLAlchemy, Pydantic, и другие.

10. Dockerfile
    Инструкции для создания Docker-образа
